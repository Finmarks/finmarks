# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** to open a private advisory.

If you can't use GitHub's private reporting, email **kaval1810@gmail.com**
with a description of the issue, steps to reproduce, and its potential
impact.

We aim to acknowledge reports within 5 business days and to publish a fix or
mitigation plan within 30 days for confirmed vulnerabilities.

## Scope

This policy covers the `finmarks` npm package, the build/validation scripts
in this repository, and the CI/CD pipelines that publish to npm, the CDN and
the discovery site.

It does **not** cover trademark, logo-authenticity or brand-misuse reports —
see [docs/trademarks.md](docs/trademarks.md) for how to request removal or
correction of a brand asset.

## Supported versions

This project is pre-1.0 (`0.x`). Only the latest published version of the
`finmarks` package receives security fixes.
